# Image Generation Prompts

SVG versions of every graphic are already included in this repo (`banner.svg`,
`coder.svg`, `profile-bg.svg`, `icons/ai-brain.svg`, `icons/glowing-circuits.svg`,
`icons/separator.svg`, `footer-wave.svg`) and are wired directly into `README.md`
— so nothing here is required to make the profile work.

If you'd rather have raster (PNG) versions with more painterly detail, generate
them with an AI image tool (Midjourney, DALL·E, Stable Diffusion, Ideogram, etc.)
using the prompts below, then drop the exported PNGs into this folder with the
matching filenames (`banner.png`, `coder.png`, `profile-bg.png`) and swap the
`.svg` extensions for `.png` in `README.md`.

All prompts share one consistent visual language: black background, dark blue
and purple gradients, neon cyan accents, thin glowing circuit lines, minimal
premium sci-fi aesthetic — inspired by Apple, Tesla, OpenAI, NVIDIA, and Vercel.

---

## banner.png — AI-themed header banner
> A wide minimal futuristic banner, pure black background fading into deep navy
> and violet, thin glowing neon-cyan neural network lines connecting small nodes,
> soft cyan and purple ambient glow on both edges, large clean sans-serif
> negative space in the center reserved for a name and title, subtle circuit-board
> trace along the bottom edge, ultra minimal, premium tech branding, 1200x300,
> inspired by Apple / Tesla / OpenAI / Vercel keynote aesthetics, no clutter, no text baked in.

## coder.png — futuristic avatar / coding workspace illustration
> A minimal flat-vector illustration of a silhouetted figure at a glowing
> holographic monitor, dark studio background (black to deep purple gradient),
> the monitor screen glows cyan-to-violet with faint code lines, a thin glowing
> ring of neural nodes orbits behind the figure, clean geometric shapes, no
> facial detail, soft rim lighting in neon cyan, premium minimal sci-fi style,
> square composition, centered.

## profile-bg.png — neural network background
> An abstract wide background texture of a sparse neural network mesh, thin
> glowing dark-blue connecting lines with a few neon-cyan and violet glowing
> nodes, pure black canvas, soft depth-of-field blur on distant nodes, extremely
// minimal, ambient, non-distracting, suitable as a full-bleed background layer,
> 1600x500, no text, no logos.
